# VoLink

VoLink is an experimental, voice-focused Android client and Linux audio bridge based on [SonoBus](https://github.com/sonosaurus/sonobus). Use an Android device as a microphone and speaker for applications running on a remote Linux computer over SSH.

**Experimental:** use with care. Linux installation and security hardening, as well as Android microphone-release and background behavior on physical devices, need further work. See [VOICE-LITE.md](VOICE-LITE.md) for architecture, build instructions, safety notes and limitations.

Original SonoBus documentation: [README.UPSTREAM.md](README.UPSTREAM.md). License: GPLv3, see [LICENSE](LICENSE) and upstream dependency notices.

The Android build compiles the included Opus 1.5.2 source. This repository is a fresh public source snapshot; the private personal project and its history are not included.
